##  Про проєкт
**ESCLAVO.AI** — це інтелектуальна екосистема для навчання програмуванню, яка перетворює суху теорію на захопливий досвід. Проєкт побудований на базі передових LLM (Large Language Models) і використовує методологію гейміфікованого мікро-навчання.

## Технологічний стек
- **Frontend:** React + Vite + TypeScript (швидка збірка та типізація).
- **Backend:** Node.js + Express (API шлюз для ШІ).
- **AI Engine:** [Groq Cloud](https://groq.com/) (Llama-3.3-70b) — забезпечує наднизьку затримку (latency) відповідей.
- **Styling:** Tailwind CSS + Футуристична неонова UI-концепція.

##  Ключові особливості (7 етапів розробки)
1. **AI-Менторство:** Роль Senior Lead Developer з унікальним стилем викладання через інженерні метафори.
2. **Practice Lab:** Система автоматичного вилучення завдань за допомогою тегів `[TASK]`.
3. **Гейміфікація:** Реалізована логіка накопичення XP, рівнів та місій.
4. **Prompt Engineering:** Складні системні інструкції з ізоляцією даних та динамічним вибором мови (Default: Ukrainian).
5. **Multi-Model Support:** Підтримка Groq, OpenAI та Gemini з автоматичним перемиканням.
